DEZEL POOL AI — دليل عربي سريع
================================

ما هذا المشروع؟
تطبيق تجريبي بلغة Python وKivy يساعدك على فتح صورة لطاولة البلياردو، ثم تحديد نقطتين يدويًا:
1) الكرة البيضاء.
2) الكرة المستهدفة.
ويحسب زاوية الخط المستقيم والمسافة التقريبية بالبكسل.

مهم:
- هذا ليس اختراقًا للعبة ولا يتصل بخوادم 8 Ball Pool.
- لا يكتشف الكرات تلقائيًا في هذه النسخة؛ عليك الضغط على مواقعها بنفسك.
- خط التصويب حساب هندسي تقريبي، ولا يحاكي دوران الكرة أو اصطداماتها بدقة.
- لم يُرفق APK جاهز؛ يجب بناء المشروع أولًا.

الطريقة الأسهل لبناء APK:
الخيار A — كمبيوتر Linux أو Ubuntu (مُوصى به)
1. فك ضغط DEZEL_POOL_AI.zip.
2. ثبّت Python 3 وJava JDK وBuildozer ومتطلبات Android.
3. افتح الطرفية داخل مجلد المشروع.
4. نفّذ:
   python3 -m venv .venv
   source .venv/bin/activate
   pip install --upgrade pip setuptools wheel
   pip install buildozer
   buildozer android debug
5. أول بناء قد يستغرق وقتًا لأنه ينزّل Android SDK/NDK والمكونات المطلوبة.
6. عند النجاح ستجد APK داخل مجلد bin/.
7. انقل ملف APK إلى هاتفك وافتحه لتثبيته. قد تحتاج السماح بالتثبيت من هذا المصدر.

الخيار B — من الهاتف
بناء APK محليًا من Termux ليس الطريق الأسهل، لأن بناء Android يحتاج SDK/NDK وأدوات متوافقة.
يمكنك:
- نقل ZIP إلى كمبيوتر Linux/Ubuntu واتباع الخطوات أعلاه؛ أو
- استخدام بيئة بناء سحابية موثوقة تدعم Buildozer، بعد مراجعة ملفات المشروع قبل رفعها.

تشغيل تجريبي على الكمبيوتر:
1. ثبّت Python 3.
2. نفّذ:
   pip install kivy
   python main.py

طريقة الاستخدام:
1. افتح التطبيق.
2. اضغط «اختيار صورة».
3. اختر لقطة شاشة محفوظة كـ PNG أو JPG.
4. اضغط على موضع الكرة البيضاء في مساحة العرض.
5. اضغط على موضع الكرة المستهدفة.
6. ستظهر زاوية تقريبية والمسافة بالبكسل.
7. اضغط «إعادة التحديد» لبدء من جديد.

استكشاف الأخطاء:
- إذا لم يفتح منتقي الصور على هاتفك، جرّب بناء التطبيق وتشغيله على الكمبيوتر أولًا؛ منتقي الملفات وأذونات التخزين تختلف حسب إصدار Android.
- إذا ظهر خطأ أثناء buildozer android debug، احتفظ بنص الخطأ كاملًا لتحديد الحزمة الناقصة.
- لا تثبّت APK من مصدر مجهول، وراجع أذونات أي تطبيق قبل تثبيته.
